## 2. I²C与SPI

I²C使用SCL时钟线和SDA数据线，通常采用开漏输出，需要上拉电阻，支持多设备共享总线。

SPI通常使用SCLK、MOSI、MISO、CS，支持全双工通信，通常速度较高。

I²C适合传感器与控制芯片，SPI适合高速Flash、显示屏等。

I²C读取寄存器的典型流程：

START → 从机地址+W → ACK → 寄存器地址 → ACK → Repeated START → 从机地址+R → ACK → 数据 → NACK → STOP。

## 3. C语言寄存器位操作

- 置位：`reg |= mask`
- 清零：`reg &= ~mask`
- 读取指定位：`reg & mask`
- 按掩码更新：`reg = (reg & ~mask) | value`

完成`register_update_bits()`，要求：

1. 检查NULL和空掩码。
2. 拒绝掩码外的非法置位。
3. 只修改指定bit。
4. 非法操作不得修改原值。

## 4. PCA9685关键知识

- 默认地址脚全为低时，7位I²C地址为`0x40`。
- 项目HAL接口使用左移后的地址`0x80`。
- MODE1：`0x00`。
- MODE2：`0x01`。
- LED0_ON_L：`0x06`。
- PRE_SCALE：`0xFE`。
- PWM通道寄存器起始地址：`0x06 + 4 × channel`。
- PWM为12位计数，有效范围0～4095。

频率计算：

`PRE_SCALE = round(fosc / (4096 × fPWM)) - 1`

典型25MHz时钟、目标50Hz，对应PRE_SCALE=121。

项目角度映射：
- 0°：约102计数。
- 90°：约307计数。
- 180°：约512计数。

以上脉宽与角度映射属于项目配置，不代表已验证MG90S的机械极限。

## 6. STM32工程修复

### PWM越界修复

`pca9685_set_pwm()`增加12位计数范围检查。

原先on=4096、off=5000会被截断后写入；修复后返回HAL_ERROR，不触发I²C写入。

### 初始化失败保护

`hand_servo_init()`在PCA9685配置失败或舵机初始写入失败时进入`HAND_MOTION_FAULT`。

- OPEN、GRAB、RELEASE拒绝启动。
- 运动命令返回ERROR。
- STOP不清除FAULT。
- UART诊断与协议处理保持运行。

## 7. 遗留风险

- MODE1热重新初始化需要进一步核对RESTART流程。
- ON与OFF相等时的PWM语义尚未调整。
- I²C同步写入仍可能延长STOP响应。
- 初始化失败前已输出的PWM不能通过Mock证明已经关闭。
- 供电、上拉、共地和实际舵机行为尚未实测。
